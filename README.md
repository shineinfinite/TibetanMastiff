## Publish on GitHub Pages
1. Extract this ZIP file.
2. Open your GitHub repository.
3. Upload the **contents** of this folder to the repository root (not the outer folder).
4. Confirm `index.html`, `style.css`, `script.js`, `README.md` and `assets/` are visible directly in the repository's Code tab.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch `main` and folder `/ (root)`, then press **Save**.
8. Wait for the GitHub Pages deployment to finish in the Actions tab.

## Editing
- Update text and sections in `index.html`.
- Change colors, spacing and fonts in `style.css`.
- Update interactions in `script.js`.
- Keep the `assets` folder beside `index.html` so the images load correctly.

## Notes
This is a static front-end site. Discord and YouTube buttons link to the official URLs above. Live Discord member counts, server login, tournament registration submissions and admin dashboards are not connected. Google Fonts are loaded online; fallback fonts are included for offline use.
