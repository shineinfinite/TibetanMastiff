## Files

- `style.css` — responsive design and visual effects
- `script.js` — navigation and official link configuration
- `assets/server-banner.jpg` — banner crop from the supplied screenshot
- `assets/server-icon.jpg` — server icon crop from the supplied screenshot

## Sections
Anime-inspired landing page, community snapshot, MLBB and Roblox features, tournament showcase, upcoming games, community features, Discord and YouTube links, and owner/creator credits.

## Publish with GitHub Pages
1. Extract this ZIP and upload all files plus the `assets` folder to the root of a GitHub repository.
2. Commit the files.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish your site.

## Customize
Edit text and event details in `index.html`; colors and styling in the `:root` section of `style.css`. Update the server statistics in `index.html` when they change. Current statistics reflect the screenshots provided.

This is a static front-end website; live server stats, tournament registration database, login and admin dashboard are not connected. Google Fonts load online with system fallbacks available offline.
